# AWS Multi-Account Login

고객사별 AWS 콘솔 계정을 관리하고, 클릭 한 번으로 **자동 로그인**(사용자명 · 비밀번호 · MFA까지)해 주는 Chrome 확장 프로그램입니다.

- 계정 목록을 팝업에서 검색 · 로그인
- IAM 사용자 로그인 자동 입력 + **TOTP(MFA) 코드 자동 생성 · 입력**
- OTP 코드 원클릭 복사
- 계정 정보 JSON / CSV 가져오기 · 내보내기
- 풍부한 키보드 단축키

---

## 설치법

이 확장은 스토어에 등록되지 않은 **로컬(언팩) 확장**으로 설치합니다.

1. 이 저장소를 내려받거나 클론합니다.
2. Chrome 주소창에 `chrome://extensions` 입력 후 이동합니다.
3. 오른쪽 위 **개발자 모드(Developer mode)** 를 켭니다.
4. **압축해제된 확장 프로그램을 로드(Load unpacked)** 클릭 → `aws-login-extension` 폴더(이 README와 `manifest.json`이 있는 폴더)를 선택합니다.
5. 툴바에 ☁ 아이콘이 나타나면 완료입니다. (핀 고정 권장)

> 코드를 수정한 뒤에는 `chrome://extensions`에서 해당 확장의 **새로고침(⟳)** 버튼을 눌러야 반영됩니다.

## 사용법

### 1. 계정 등록

1. 툴바의 ☁ 아이콘을 클릭해 팝업을 엽니다.
2. **+ 계정 추가** (또는 팝업에서 `Alt+N`) → 관리 페이지가 열립니다.
3. **+ 새 계정 추가** (또는 관리 페이지에서 `Ctrl+Alt+N`)를 눌러 폼을 채웁니다.

| 항목 | 필수 | 설명 |
|---|:---:|---|
| 고객사 이름 | ✅ | 목록에 표시될 이름 (아바타 색·이니셜 자동 생성) |
| AWS 계정 ID | ✅ | 12자리 숫자. 로그인 URL의 서브도메인으로 사용되어 **계정 입력 단계가 생략**됩니다 |
| IAM 사용자 이름 | ✅ | 로그인할 IAM 사용자 |
| 비밀번호 | ✅ | 👁 버튼으로 표시/숨김 |
| MFA 비밀키 | ⬜ | Base32 TOTP 시크릿. 입력 시 실시간으로 형식 검증 + 현재 코드 미리보기 |
| 메모 | ⬜ | 리전, 담당자 등 자유 메모 |

4. **저장**을 누르면 목록에 추가됩니다.
5. 왼쪽 사이드바에서 항목을 **드래그**하면 순서를 바꿀 수 있습니다. (이 순서가 `Alt+1~9` 로그인 번호 기준이 됩니다)
6. 사이드바 상단 검색창에서 이름·계정 ID로 **필터링**할 수 있습니다. (검색 중에는 순서 변경 비활성화)

### 2. 자동 로그인

- 팝업에서 계정의 **로그인** 버튼을 누르거나, 검색 후 `Alt+숫자` / `Enter`를 누릅니다.
- 계정 전용 로그인 URL(`https://<계정ID>.signin.aws.amazon.com/console/`)로 새 탭이 열리고, 확장이 다음을 자동으로 처리합니다.
  1. 사용자 이름 입력 → 다음
  2. 비밀번호 입력 → 로그인
  3. **MFA 코드** 자동 생성 후 입력 → 제출 *(MFA 비밀키가 등록된 계정만)*
- 자동 입력에 사용된 로그인 정보는 사용 즉시 임시 저장소에서 삭제됩니다.

### 3. OTP 코드 복사

- 팝업의 계정 카드에서 **로그인 버튼을 제외한 영역**(또는 OTP 코드 숫자)을 클릭하면 현재 6자리 OTP가 **클립보드에 복사**됩니다. ("복사됨!" 표시)
- 코드는 30초마다 갱신되며, 남은 시간이 링과 숫자로 표시됩니다. (5초 이하 빨간색)

### 4. 가져오기 / 내보내기

관리 페이지 왼쪽 아래에서:

- **⬆ 내보내기** — 확인 → JSON / 취소 → CSV 로 계정 전체를 파일로 저장
- **⬇ 가져오기** — JSON 또는 CSV 파일 선택. 중복(같은 계정 ID)은 덮어쓰기/새 계정만 추가 중 선택
  - CSV 필수 열: `name, accountId, username, password` (선택: `mfaSecret, note`)

## 키보드 단축키

### 팝업

| 단축키 | 동작 |
|---|---|
| (팝업 열림) | 검색창 자동 포커스 |
| `/` · `Ctrl/Cmd+K` | 검색창 포커스 |
| `Alt+1` ~ `Alt+9` | **현재 검색 결과** 기준 N번째 계정으로 로그인 |
| `Enter` (검색창) | 검색 결과 **첫 번째** 계정으로 로그인 |
| `Esc` (검색창) | 검색어 초기화 |
| `Alt+N` | 계정 관리 페이지 열기 |

### 관리 페이지

| 단축키 | 동작 |
|---|---|
| (페이지 열림) | 사이드바 검색창 자동 포커스 |
| `/` · `Ctrl/Cmd+K` | 사이드바 검색창 포커스 |
| `Esc` (검색창) | 검색어 초기화 |
| `Ctrl+Alt+N` | **새 계정 추가** 폼 열기 |

> `Alt+숫자`는 Mac(Option+숫자)의 특수문자 입력 문제를 피하기 위해 물리 키(`event.code`) 기준으로 동작합니다.

## 보안 참고

- 모든 계정 정보(비밀번호 · MFA 비밀키 포함)는 브라우저의 `chrome.storage.local`에 **평문으로** 저장됩니다. 공용 PC에서는 사용을 권장하지 않습니다.
- MFA 비밀키는 TOTP 코드 생성을 위해 저장됩니다. 이는 곧 이 확장이 사실상 2차 인증을 대신 수행함을 의미하므로, 하드웨어/모바일 인증기의 격리 이점은 사라집니다. 위험을 이해하고 사용하세요.
- 자동 로그인용 임시 데이터(`pendingLogin`)는 로그인 페이지에서 읽는 즉시 삭제됩니다.
- 내보낸 JSON/CSV 파일에도 비밀번호와 MFA 비밀키가 평문으로 포함됩니다. 파일 관리에 주의하세요.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 정의 (MV3), 권한, 콘텐츠 스크립트 |
| `popup.html` / `popup.js` / `popup.css` | 계정 목록 · 검색 · 로그인 · OTP 복사 팝업 |
| `options.html` / `options.js` / `options.css` | 계정 추가/편집 · 순서 변경 · 가져오기/내보내기 관리 페이지 |
| `content.js` | AWS signin 페이지에서 사용자명 · 비밀번호 · MFA 자동 입력 |
| `totp.js` | Base32 시크릿으로 TOTP(6자리, 30초) 코드 생성 |
| `background.js` | 서비스 워커 |
| `icons/` | 확장 아이콘 (16 · 48 · 128) |
